# Random Wheel V1.2 — release gates

## Track A: engineering (required before production)

- [ ] Astro type checks, unit tests, build and static route audit succeed in GitHub Actions.
- [ ] Chromium E2E tests pass: range, no-repeat, large range, keyboard/mobile, escaped custom entries.
- [ ] Manual pointer alignment / weight proportion / reduced-motion checks and cross-browser tests.
- [ ] Eight launch tool routes and five support routes are accessible.
- [ ] Static content, unique titles, canonical and index/noindex status are correct.
- [ ] Cloudflare Pages deployment ID verified from real deployment.
- [ ] Custom .com, HTTPS, www and Pages production redirects checked after domain binding.

## Track B: SEO (only after verified production launch)

- [ ] GSC domain ownership verified.
- [ ] Sitemap submission verified separately from actual indexing.
- [ ] Day ~30: index diagnosis and US nonbrand query observations.
- [ ] Day 30–60: two comparable 28-day windows.
- [ ] Day 60–90: decision to expand / merge / continue observing.

## Strict boundaries

- PUBLIC_INDEXABLE=false until production custom domain and HTTPS/301 are verified.
- Never call 0 impressions when GSC data has not yet been obtained.
- Preview, production pages.dev and custom .com are different deployment states.
- 26 planned URLs are a backlog, NOT 26 automatically indexable pages.
- Do not publish the complete proprietary Semrush export in this public repository.
- Never claim Ads approval or verified earnings before platform confirmation.
