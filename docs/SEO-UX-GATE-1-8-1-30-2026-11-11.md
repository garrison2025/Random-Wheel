# UX and Search-Intent Final Gate — 1–8 and 1–30 Candidate Pages

**Review date:** 2026-11-11. **Scope:** only \`/random-number-wheel/1-8/\` and \`/random-number-wheel/1-30/\`.  
**Evidence tier:** source-code review, reproducible browser tests, public competitor-page content. This is **not** a verified Google US top-10 ranking report, not Search Console data, and not a real teacher field study.
**Decision:** Product workflows improved; **do not remove \`noindex\`** and do not add either URL to \`LAUNCH_ROUTES\` yet.

## Search intent and why each route could exist independently

### 1–8: numeric picker first, allocation workflow second
- **Primary query:** \`random number 1-8\`, which usually asks for a quick number from a small 8-outcome pool.
- **Secondary actionable job:** allocate numbered stations to up to eight teams in **one** non-repeating operation.
- **Direct comparators:** [NamesOnWheel 1–8](https://namesonwheel.com/pick-a-number-1-8-wheel/) already offers editable entries, sound, spin settings and random group/task selection; [Spinfetti Team Picker](https://www.spinfetti.com/en/tools/team-picker) already supports splitting individuals into teams; [WheelPicker](https://www.wheelpicker.io/) has general team and number wheels.
- **Our real distinction:** a **station-number assignment**, not a generic group maker. Input teams \`Blue, Red, Green\`; output has numbered stations without repeats, visibly sorted by station, a one-click clipboard pairing list and a station-sorted CSV.
- **Round-3 UX changes:** hero shortcuts to either normal 1–8 wheel or station allocation; station-first table and copy; invalid or edited inputs reset stale results; explanatory privacy note.
- **Caution:** the extra workflow does not prove people searching for "random number 1-8" want station allocations. The normal wheel remains visible first.

### 1–30: numeric picker first, classroom flow as optional activity
- **Primary query:** \`random number 1-30\`, a simple picker with substantial classroom overlap.
- **Secondary actionable job:** absence-aware roll-call in a class of up to 30.
- **Direct comparators:** [SpinPicker 1–30](https://spinpicker.io/wheel/1-30), [Peabody Teach 1–30 number generator](https://teach.peabody.kids/number/1-30), [Peabody Teach 1–30 wheel](https://teach.peabody.kids/wheel/numbers-1-30), and [Tally & Table name picker](https://tallyandtable.com/randomizers/random-name-picker/). Competitors already support no-repeat and marking absent students.
- **Our real distinction:** an *entire shuffled future order* plus a **progressive reveal**, an accessible 30-button absence grid, progress text, undo action and full CSV, while keeping the optional ordinary 1–30 wheel.
- **Round-3 UX changes:** hero shortcuts; tap absent/present number and keep input synchronized; count absent/present; generate an order without leaking the future calls in on-screen rows; next/undo; progress and explicit note that full CSV reveals upcoming calls.
- **Caution:** this improves classroom utility but still requires a real mobile/iOS teacher test and query-intent research. The full export intentionally contains the future order, so it must be labeled clearly.

## Scope and privacy

No server or account is required to run either activity. User input is processed in the browser. The 1–8 clipboard action is initiated only after clicking Copy. CSV downloads are user-triggered. The named team input is not auto-saved by these activity panels. The 1–30 absence state is temporary in this workflow. This is not an independently audited privacy or security certification.
